# Data Professional Survey Dashboard

This Power BI dashboard presents a detailed breakdown of survey responses from 630 data professionals across different roles and countries. The analysis provides insights into salaries, work-life balance, job satisfaction, and more.

##  Objective

To visualize and explore trends in the data industry based on real survey results, helping aspiring professionals understand career expectations, challenges, and opportunities.

##  Dashboard Features

- **Count & Age of Survey Takers**: Total respondents and their average age.
- **Happiness Scores**:
  - Work-Life Balance
  - Salary Satisfaction
- **Job Market Difficulty**: How hard it is to break into data roles.
- **Average Salary by Job Title**: Compare income across Data Scientists, Analysts, Engineers, and others.
- **Country Breakdown**: Top countries where survey participants are located.
- **Favorite Programming Languages**: Languages preferred by data professionals in different roles.

##  Tools Used

- Power BI
- Data modeling & DAX
- Survey data preprocessing

##  Key Insights

- Python is the most popular language among all data roles.
- Data Scientists earn the highest average salary.
- Most respondents find it *neither easy nor difficult* to enter the data field.
- Salary satisfaction is generally lower than work-life balance.
